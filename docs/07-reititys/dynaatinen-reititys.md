# Dynaaminen reititys

**Dynaaminen reititys** (*dynamic routing*) on prosessi, jossa reitittimet
jakautuvat reitintaulut keskenään automaattisesti. Tämän vastakohta on
[staattisessa reitityksessä](staattinen-reititys.md), jossa reitit määritellään
manuaalisesti.

## Mitä tämä osio kattaa?

Tässä osiossa käsitellään dynaamisia reitintautoja, erityisesti
[OSPF:ia](ospf.md), joka on yleisin interior-gate-way protokiijat.
