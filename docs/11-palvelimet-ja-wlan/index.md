# Palvelimet, päätelaitteet ja WLAN

Tämä osio käsittelee kolmea keskeistä verkonteknologian aluetta: **palvelimet** (servers), **päätelaitteet** (clients/end devices) ja **langattomat verkot** (WLAN). Tämä dokumentti perustuu **IEEE 802.11** -standardiin (WLAN), **RFC 2616** (HTTP-pohjaiset palvelimet) ja yleisiin palvelinarkkitehtuureihin.

## Mitä tämä osio käsittelee?

| Sivu | Aihe | Keskeinen kysymys |
|------|------|-------------------|
| Palvelimet | Palvelintyypit, VM:t, containerit | Miten palvelimet toimivat? |
| Päätelaitteet | PC:t, läppärit, päätelaitteet | Miten laitteet liittyvät verkkoon? |
| Access Pointit | WLAN:n perusteet, SSID, kanavat | Miten langattomat verkot muodostavat? |
| WLAN-salaus | WEP, WPA2, WPA3 | Miten langattomat verkot suojataan? |

## Miksi nämä ovat tärkeitä?

| Elementti | Rooli | Esimerkki |
|-----------|------|-----------|
| **Palvelin** | Tarjoilee palveluita | WWW-palvelin |
| **Päätelaitteisto** | Käyttää palveluita | Työasema |
| **WLAN** | Langaton yhteys | Kotiverkko |
