# Claude Code – Tietoverkot

Projektin `.claude/` sisältää Claude Coden ohjeet, säännöt ja tehtäväkohtaiset skillit.

## Rakenne

- `CLAUDE.md` – projektin yleiset ohjeet
- `rules/` – pysyvät projektisäännöt
- `skills/` – tehtäväkohtaiset toimintamallit

## Työskentely

Pienissä muutoksissa käytä `quick-docs-edit`-skilliä.

Tavoite:

- mahdollisimman pieni konteksti
- mahdollisimman vähän tiedostojen lukemista
- vain pyydetyt muutokset
- nopea toteutus ja tarvittava tarkistus

Älä tutki koko projektia, ellei tehtävä sitä edellytä.

## Laajemmat sisältötehtävät

Tietoverkkojen sisältöprojektin suunniteltu tuotantoprosessi ja tehtävien tila ovat `todo/`-hakemistossa.

`todo/sisalto-todo*.md` toimii prosessin tilana ja jatkamisen lähteenä.

## Periaate

**Pieni tehtävä → pieni konteksti → pieni muutos → nopea tarkistus.**
